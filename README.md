## Состав проекта

- `pygamesteel.py` — программа с зашитыми в код ошибками
- `pygamesteel_fixed.py` — исправленная версия програмы с ошибками
- `requirements.txt` — тут зависимости Python
- `nmapres.txt` — файл для результатов Nmap
- `test_privesc.sh` — скрипт для проверки поведения SUID

## Изученные темы

- пользователи и группы Linux
- права `r`, `w` и `x`
- команды `chmod`, `chown` и `chgrp`
- POSIX ACL
- SUID и эффективный UID
- sticky bit
- процессы Linux
- различия между `find` и `locate`
